# Legacy CLI Browser Prototypes (Archived)

The files in this directory (`provBook.R`, `provBookR.prov.browser.R`, etc.) contain early 2019 interactive terminal CLI prototypes for querying provenance line-by-line in R.

> **Note**: These scripts are archived reference code and are not part of the active, exported `provBookR` package API. 

For current package usage, see `docs/usage.md` and use the active SvelteKit publishing engine:
* `publish_codex(script, output_dir)`
* `preview_codex(output_dir, port)`
